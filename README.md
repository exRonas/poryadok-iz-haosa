# Порядок из хаоса

Веб-приложение «лаборатория визуальной математики»: семь опытов про случайность (доска Гальтона, случайное блуждание, скрытая картинка, треугольник Серпинского, от шума к изображению, как одна точка меняет среднее, силуэт точками) и учебный режим по математической статистике. Все вычисления выполняются в браузере.

## Запуск на защите

Откройте файл `dist/index.html` двойным щелчком. Интернет и установка не нужны.

## Учебный режим

Кнопка «Учебный режим» в шапке (адрес `#study`) открывает каталог курсов по математической статистике для студентов. Готовы курс 1 «Описательная статистика» (выборка и частоты, среднее и медиана, разброс, выбросы), курс 2 «Распределения» (биномиальное распределение, матожидание и дисперсия, случайное блуждание, переход к нормальному), курс 3 «Предельные теоремы» (частота и вероятность, усреднение шума, центральная предельная теорема, порядок из хаоса) и курс 4 «Оценивание и Монте-Карло» (оценка доли, площадь точками, точность 1/√n, метод индикаторов) — по четыре урока и итог курса. В каждом уроке есть идея с формулой, учебный опыт, вопрос по графику и ссылка на полный эксперимент.

Код учебного режима лежит в `src/course/`, прогресс сохраняется в браузере (ключи `matstat-course-v2/…`). 3D-картинки и анимация отрисованы в Blender — как их перерисовать, описано в `tools/render/README.md`.

## Разработка

```
npm install
npm run dev
```

## Проверка и сборка

```
npm test
npm run build
```

Сборка создаёт один файл `dist/index.html`, в который встроены код, стили и шрифты.
